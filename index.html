Bộ công cụ văn phòng tất cả trong một

Xử lý PDF, Excel, Word, Ảnh — nhanh, riêng tư, miễn phí.

PDF

Gộp PDF

Excel

Excel → CSV

Chuyển sheet đầu tiên sang file CSV.

Excel → JSON

Xuất dữ liệu dạng JSON.

Gộp Bảng tính

Word

Xem trước .docx

Đọc và hiển thị nội dung Word trực tiếp.

Word → HTML / Text

Chuyển .docx sang HTML hoặc văn bản thuần.

Word → PDF

Chuyển file .docx sang PDF, giữ định dạng cơ bản.
